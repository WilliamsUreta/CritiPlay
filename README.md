Este Proyecto es un App de Criticas de VideoJuegos.

Integrantes:
-Javier Vieytes
-Williams Ureta
-Bastian Abello

Contiene las funciones tanto de inciar sesión como de cerrar la sesión, 
la de crear reseñas como la de ver las reseñas y 
contiene un apartado de perfil en el que se puede actualizar el perfil.
